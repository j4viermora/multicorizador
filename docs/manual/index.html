¿Qué es Ruka?

Plataforma SaaS multi-tenant para cotizar, comparar y vender seguros de viaje.

Un visitante o un productor arma una búsqueda de viaje. Ruka consulta en paralelo a varias aseguradoras aliadas (providers), persiste cada respuesta como un QuoteResult, y muestra un comparador. Cuando alguien compra, el sistema debe terminar con una Policy real asociada al plan elegido.
